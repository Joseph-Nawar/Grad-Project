# Demonstration shot list

Capture status: **PENDING**. No screenshots or video are included until a
manual browser capture is completed.

Use a browser viewport of approximately 1440×1000 pixels and capture these
PNG files under `docs/assets/screenshots/`:

| Filename | Required content |
| --- | --- |
| `collector-inputs.png` | Collector context, symptoms, and media inputs with pseudonymous data. |
| `collector-result.png` | Evidence level, modality summaries, warnings, and non-diagnostic wording. |
| `clinician-queue.png` | Submitted/reviewed queue with short case references. |
| `clinician-case-review.png` | Readable context, symptoms, submitted image/audio, and stored assessment. |
| `clinician-review-outcome.png` | Completed agreement or override outcome and notes. |

Do not capture full names, national identifiers, addresses, internal paths, or
real patient media. Record the browser and application versions used for the
capture in the release notes.
