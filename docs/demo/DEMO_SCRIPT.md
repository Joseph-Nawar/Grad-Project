# Demonstration script

Target duration: 3–5 minutes.

1. Introduce the project as research screening and triage support, not
   diagnosis.
2. In the collector app, show pseudonymous context, acute symptoms, face
   capture, and the fixed English speech sentence.
3. Run the assessment and explain that the displayed result is a multimodal
   evidence level with quality warnings.
4. Submit the case and show the generated case reference.
5. In the clinician app, open the submitted case and review the exact stored
   assessment, image, audio, context, symptoms, and provenance.
6. Record either agreement with the proposed triage urgency or a documented
   override. Emphasize that the review decision is separate from the stored
   assessment snapshot.

Do not state or imply diagnosis, calibrated probability, clinical validation,
or autonomous action. Clinical wording review remains pending.

The speech branch was developed using English TORGO recordings. Use the
provided English sentence for this demonstration; Arabic and other languages
have not been validated for this branch.
