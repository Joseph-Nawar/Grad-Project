# Stage 5 evidence

This directory contains compact machine-readable Stage 5 evidence. It records the frozen baseline, isolated conversion environment, conversion recipes and failures, micro/full-adapter parity, clean-subprocess runner benchmarks, viable bundle comparison, representative fused risk-band parity, and the final promotion decision.

Candidate artifacts and conversion environments live only under the ignored `.stage5/` workspace. The only promoted artifacts are the files under `models/edge/` declared by `config/edge_runtime_registry.json`. The original face, speech, and metadata artifacts remain the explicit fallback.
